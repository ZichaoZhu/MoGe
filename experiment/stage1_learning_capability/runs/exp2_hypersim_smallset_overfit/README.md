# exp2_hypersim_smallset_overfit

## 实验目标

验证 SSR 能否从单帧过拟合扩展到多场景小数据训练，并检查多样本采样、冻结基础模型
特征缓存、训练集评测和独立场景验证是否可以端到端运行。

## 相较 exp1 的变更

- 训练数据从 1 帧扩大到 3 个场景、共 24 帧。
- 增加 1 个完全不参与训练的场景，共 8 帧作为验证集。
- 批量大小从 1 增加到 2，训练步数从 200 增加到 2000。
- 预先缓存冻结的 MoGe-2 基础点图和 DINO 特征，训练阶段只运行 SSR。
- 增加逐帧指标、训练/验证曲线和半径 1 像素的深度边界 F1。

## 数据划分

每个场景沿相机轨迹间隔采样 8 帧，避免连续帧高度重复。

| 划分 | 场景 | 帧 |
|---|---|---|
| 训练 | `ai_001_001` | 0, 14, 28, 43, 56, 71, 85, 99 |
| 训练 | `ai_018_003` | 0, 14, 28, 42, 57, 71, 85, 99 |
| 训练 | `ai_036_002` | 0, 14, 28, 42, 57, 71, 85, 99 |
| 验证 | `ai_055_003` | 0, 14, 28, 42, 57, 71, 85, 99 |

三个训练场景分别包含浴室、客厅和图书馆；验证场景为独立餐厅。只使用色调映射 RGB、
欧氏深度和相机内参，不使用法线数据。

## 实验配置

- 基础模型：`Ruicheng/moge-2-vitl-normal`
- 运行设备：物理 GPU 2，通过 `CUDA_VISIBLE_DEVICES=2` 映射为 `cuda:0`
- 可训练模块：仅 SSR，基础模型和二维预测头全部冻结
- 图像尺寸：192×256
- 批量大小：2
- 精修次数：K=3
- 优化器：AdamW
- SSR 学习率：2e-4
- 权重衰减：1e-2
- 训练步数：2000
- 评测间隔：200 步
- 损失：全局仿射不变点图损失、α={4,16,64} 径向局部损失、边缘角度损失

## 验收条件

- 零初始化 K=3 与 K=0 严格一致。
- 训练过程中不出现 NaN 或 Inf，检查点能够保存。
- 至少 75% 的训练帧深度 Rel 得到改善。
- 训练集平均深度 Rel 相对 K=0 至少下降 50%。
- 验证集只记录趋势，不作为本实验的强制通过条件。

## 实验结果

### 核心结果

零初始化 SSR 的 K=3 点图与 K=0 点图逐元素完全相同，最大绝对误差为 0。训练集
24/24 帧的深度 Rel 均得到改善，达到预设的两项过拟合验收条件。

| 指标 | 训练集 K=0 | 训练集 K=3 | 变化 |
|---|---:|---:|---:|
| 点图 Rel | 3.666% | 1.912% | 相对下降 47.85% |
| 深度 Rel | 3.163% | 1.271% | 相对下降 59.83% |
| 深度 δ1.01 | 39.64% | 72.64% | 增加 33.00 个百分点 |
| 深度 δ1.25 | 98.29% | 99.33% | 增加 1.04 个百分点 |
| 边界 F1 | 0.8700 | 0.8844 | 增加 0.0144 |

三个训练场景的深度 Rel 分别相对下降 64.28%、54.42% 和 61.18%，不是由单一场景
改善造成的。前 50 步平均损失为 0.08553，后 50 步为 0.05137，相对下降
39.94%。训练集深度 Rel 在第 1800 步达到最低值 1.240%，最终为 1.271%。

### 独立场景结果

| 指标 | 验证集 K=0 | 验证集 K=3 | 变化 |
|---|---:|---:|---:|
| 点图 Rel | 8.278% | 8.789% | 相对上升 6.18% |
| 深度 Rel | 6.997% | 7.362% | 相对上升 5.21% |
| 深度 δ1.01 | 19.44% | 15.66% | 下降 3.78 个百分点 |
| 深度 δ1.25 | 93.68% | 93.43% | 下降 0.25 个百分点 |
| 边界 F1 | 0.8779 | 0.8537 | 下降 0.0242 |

验证集只有 3/8 帧的深度 Rel 改善。该结果符合本实验的定位：SSR 已证明能够在多场景
小训练集上学习几何残差，但 24 张训练图不足以获得跨场景泛化。

### 资源与稳定性

- 正式训练耗时 1243.7 秒（20.73 分钟），平均 0.622 秒/步。
- PyTorch 记录的峰值已分配显存为 5.95 GiB。
- 全程未出现 NaN、Inf 或运行时错误，梯度裁剪正常生效。
- 正式检查点能够恢复优化器和 SSR 状态，并从第 2000 步继续完成第 2001 步。
- 服务器完整测试为 25 项通过；16 条警告来自 Matplotlib/PyParsing 和 PyTorch
  调度器测试中的既有弃用提示。

### 三维旋转动画

训练完成后使用同一个 step 2000 检查点补充了两张 GT/K=0/K=3 离轴旋转 GIF。两者
均在点图完成光轴仿射对齐后，以相同虚拟相机从 -35° 到 +35° 往返旋转：

- [训练细结构 GIF](artifacts/orbits/train_fine_structure_orbit.gif)：使用
  `ai_036_002/frame.0042` 的吊灯链条和梯子区域。该训练样本用于展示模型的拟合
  能力，窗口按 K=0→K=3 点图 Rel 改善选择，因此不能作为无偏泛化证据。点图 Rel
  从 6.374% 降到 2.765%，边界 F1 从 0.8689 升到 0.9159。
- [独立验证细结构 GIF](artifacts/orbits/val_fine_structure_orbit.gif)：使用
  `ai_055_003/frame.0057` 的竖向细杆，窗口只按真值细结构候选强度选择，不读取
  预测质量。K=3 的深度 Rel 从 7.320% 降到 6.895%，但点图 Rel 从 9.390%
  升到 9.877%，边界 F1 从 0.8861 降到 0.8616；旋转后可以看到细杆和邻近表面的
  三维厚度与扭曲加重。

这两张动画没有改变 exp2 的训练结果，而是把原有结论直观化：SSR 在参与训练的结构
上能够明显修正三维几何，但在独立场景中，二维深度数值略有改善并不代表三维点图真的
更准确。完整逐轮面板、选区和机器可读指标保存在
[artifacts/orbits](artifacts/orbits)，生成命令见 [render_orbits.sh](render_orbits.sh)。
补充可视化相关测试为 8 passed、14 warnings，3.42 秒，日志错误扫描为空。

## 结论与限制

本实验通过了“小数据训练集过拟合”验收：精修器不仅能记住单帧，还能同时改善三个
不同场景的 24 帧几何。曲线和定性图中，训练图的局部误差明显减少。

但独立餐厅场景的所有汇总指标均退化，因此本实验不能作为 MoGe-3 泛化效果的证据。
当前还冻结了基础模型、只使用 192×256 分辨率，并采用自定义的对数深度边界阈值；
这些结果不能直接与论文主表比较。下一阶段应在保持独立验证集的前提下扩大场景数量，
观察验证误差何时开始随训练数据增加而下降，再考虑联合微调基础模型。
