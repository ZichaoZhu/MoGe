# 阶段四：损失、细结构监督与参数梯度诊断

## 阶段目标

在稳定性问题得到定位后，继续解释为什么 SSR 能拟合训练结构，却难以在验证集和测试集
形成稳定的独立收益。

## 原实验映射

| 原实验 | 内容 | 主要结果 |
|---|---|---|
| [Exp25](runs/exp25_loss_gradient_structure_audit/README.md) | 损失梯度与细结构监督审计 | 训练 ROI 目标下降 14.91%，验证/测试上升 1.81%/9.64%；修正矩形输入 edge 分母 |
| [Exp26](runs/exp26_ssr_parameter_gradient_conflict_audit/README.md) | SSR 参数梯度冲突审计 | edge 参数梯度仅为 global 的 8.16%–14.28%；超过 99% 梯度能量位于输出层 |

## 阶段结论

- edge loss 在像素梯度图上并不弱，但与 GT 几何边界的富集有限。
- 经过共享网络参数映射后，edge 监督远弱于 global 目标；仅提高标量权重未必能直接
  获得对应的结构参数更新。
- 输出层吸收了绝大多数梯度能量，SSR 内部表征受到的细结构塑形较弱。
- 去除输出层后，Train/Val 与 Train/Test 合计梯度余弦约为 0.446/0.447，说明不同
  数据划分对内部参数的优化方向存在明显差异。

因此，留出集退化不能只归因于归一化。下一阶段应在控制稳定性的前提下验证更直接的
结构监督、采样策略或梯度平衡方法，而不是继续堆叠短诊断实验。
