# exp4_hypersim_multiscene_generalization

## 实验目标

验证仅训练 SSR 时，增加 Hypersim 场景多样性和输入分辨率能否把 exp2 的训练集过拟合
转化为跨场景泛化。主要问题不是训练集能否继续改善，而是 K=3 能否在未参与训练的
场景上稳定优于 K=0 基础模型，尤其是三维点图和细结构。

## 论文依据与复现边界

- 与论文表 3 的消融实验一致，本实验冻结 MoGe-2 基础模型，只训练 SSR。
- 与论文一致，训练使用 K=3，并在推理时比较 K=0/1/3/5。
- 论文主定量评测约使用 $840^2$ 分辨率；本实验采用 384×512，是单机小规模验证的
  中间档，不是论文完整分辨率。
- 本实验没有执行论文主模型的两阶段联合训练，因此只能检验 SSR 自身的泛化，不能
  代表完整 MoGe-3。
- 不使用法线数据，也不训练法线预测头。

## 数据划分

从已授权只读访问的 `/nas1/datasets/hypersim/raw` 复制 RGB、欧氏深度和相机参数到
实验目录。每个场景均匀采样 16 帧：

| 划分 | 场景数 | 帧数 | 用途 |
|---|---:|---:|---|
| 训练 | 20 | 320 | SSR 梯度更新 |
| 验证 | 4 | 64 | 每 500 步评测并选择检查点 |
| 测试 | 4 | 64 | 检查点确定后仅评测一次 |

三个划分使用互不重叠的 `ai_XXX` 源场景组，避免同一房屋的不同变体跨划分泄漏。
验证集保留 exp3 使用过的 `ai_055_003` 作为连续性案例；测试集四个场景此前没有用于
训练、调参或可视化选择。

## 预注册配置

- 基础模型：`Ruicheng/moge-2-vitl-normal`；
- 可训练模块：仅 SSR；
- 分辨率：384×512；
- DINO token 数：2500；
- 有效批量大小：2；每次反向的微批量为 1，累积 2 次后更新；
- 训练步数：8000；
- 优化器：AdamW，学习率 2e-5，权重衰减 1e-2；
- 损失：全局、α={4,16,64} 局部、边缘角度损失，权重均为 1；
- 验证间隔：500 步；
- 检查点选择：验证集点图 Rel 最低；
- 物理 GPU：2；
- 随机种子：47。

正式训练前使用 GT 深度的论文附录 B.1 粗候选规则生成候选表，再仅根据训练前的
GT/RGB 候选图锁定验证样本 `ai_055_003/frame.0013`（竖向木格）和测试样本
`ai_046_001/frame.0079`（植物枝叶与细框），不读取模型预测。训练完成后为这两个
固定样本生成 K=0/1/3/5 面板和 GT/K=0/K=3 旋转 GIF。

## 验收标准

### 主要标准

- 最佳检查点的验证集 K=3 点图 Rel 低于 K=0；
- 测试集 K=3 点图 Rel 低于 K=0，且超过一半测试帧得到改善；
- 测试集边界 F1 相比 K=0 的下降不超过 0.005。

### 细结构诊断

- 固定验证和测试 ROI 的 K=3 点图 Rel 低于 K=0；
- 离轴 GIF 中 K=3 不出现比 K=0 更明显的弯曲、粘连或飞点；
- K=5 不出现明显迭代发散。

粗候选没有使用论文的 SAM2 分割扩张和逐实例局部对齐，因此 ROI 数值只用于诊断，
不与论文 Local 指标直接比较。

## 运行时间预估

384×512、batch=2、K=3 的初始 5 步短基准峰值显存为 14,773,041,664 字节
（13.76 GiB）。长序列训练发现高有效像素批次会因三轮稀疏图与三类损失同时保留
计算图而产生远高于短基准的瞬时峰值，因此正式训练保持有效 batch=2，但改为
microbatch=1、梯度累积 2 次。该调整不改变每步采样数和损失的批量平均定义，但
BatchNorm 的统计范围从两幅图的活动体素变为单幅图的活动体素。正式实验预计
2–4 小时。

长序列异常追踪最初在 `SparseImplicitGemmFunctionBackward` 观察到 NaN；进一步在
稀疏卷积反向之前逐项检查点图梯度后，确认真正来源是 K=3 全局对齐损失先产生 Inf。
修复为不经过已求解的尺度/平移反传后，继续显式使用 `MaskImplicitGemm`。曾验证过的
`Native` 备用路径在长序列中发生 CUDA illegal memory access，因此未用于最终训练。

原预注册学习率为 2e-4；在训练压力测试中，它在约 1400 步后令全局对齐失效并最终
产生非有限损失。论文的 2e-4 对应全局 batch 96，而本实验有效 batch 仅为 2。最终
正式结果因此使用 2e-5 从 SSR 零初始化开始完整训练 8000 步，不复用压力测试权重或
优化器状态；训练期间保留逐项点图梯度有限性检查。

## 实验结果

### 结论

本实验完成了 8000 步稳定训练，但预注册的跨场景泛化假设**未通过**。SSR 学会了
训练场景：最终 K=3 令训练集点图 Rel 相对降低 13.03%，且 95.94% 的训练帧改善；
然而验证集点图 Rel 相对恶化 3.33%，因此按验证集选出的最佳检查点仍是 step 0，
即 SSR 零初始化的严格恒等映射。

测试集出现了很小的平均点图改善（0.42%），且 56.25% 帧改善，但边界 F1 下降
0.0260，明显超过预注册允许的 0.005。固定细结构区域和离轴 GIF 也显示，反复精修
会逐渐加重局部偏移。因此，这个结果证明“小规模合成数据 + 冻结基础模型 + 仅训练
SSR”足以拟合训练场景，却不足以复现论文报告的局部几何泛化收益。

### 最佳验证检查点

最佳检查点为 step 0，验证点图 Rel 为 0.064145。输出层零初始化使 K=1/3/5 与 K=0
完全一致，最大恒等误差为 0。这一检查点适合表示严格的模型选择结果，但不能表示
SSR 在训练后的行为。

### 最终 step 8000 检查点

### 训练稳定性与修正

正式运行前的压力测试暴露并修复了三类问题：

1. 分组加权中位数在 CUDA float32 大坐标上出现索引越界，累加坐标改为 float64 并
   增加边界钳制和回归测试；
2. 全局仿射对齐的尺度解在退化批次附近产生极大梯度。依据包络定理，损失现在通过
   已求解且 `detach` 的尺度/平移更新预测点，只对对齐后的点误差反传；
3. 长序列稀疏卷积在自动算法选择和 `Native` 路径上不稳定，最终固定使用
   `MaskImplicitGemm`，并使用 microbatch=1、梯度累积 2。

原计划的 2e-4 学习率在有效 batch=2 时约 1400 步后发散；最终正式结果以 2e-5 从
SSR 零初始化重新训练，不加载失败权重。8000 步期间无 NaN，最终损失从 0.04350
降至 0.02460。
