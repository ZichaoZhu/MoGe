# Exp28：平滑有界残差的短程联合训练

## 实验问题

Exp16 从 Exp15 step 800 进入联合阶段后，在 step 820 检测到单轮最大绝对
对数深度残差 `0.5331`，并在反向传播前安全终止。Exp28 保持 Exp16 的数据、
权重、随机种子、学习率和梯度路由不变，只在每轮 SSR 更新之前加入：

\[
\Delta\zeta=0.1\tanh(\Delta\zeta_{\rm raw}/0.1).
\]

目标是判断“限制单轮几何更新步长”能否让联合阶段稳定完成，而不是直接宣称
优于论文原方法。

## 固定配置

- warm start：Exp15 step 800；
- 100 张 train、16 张 validation、16 张 test；
- step 801–1000 全部解除 detach，二维头与 SSR 联合更新；
- DINO 冻结；
- SSR/head 学习率：`2e-6 / 5e-7`；
- 全局 batch 8，microbatch 1，训练 `K=3`；
- 每轮实际残差平滑限制在 `(-0.1, 0.1)`；
- 原始残差超过 `2.0` 时仍终止，避免平滑上限掩盖内部发散；
- 每 50 步评测，以训练集细结构 K=3 Point Rel 选择最佳检查点。

训练期间同时记录原始残差、实际残差、接近上限的像素比例、深度跨度、梯度和
显存。若大量像素长期贴近上限而原始残差继续增大，应判定为“坍塌被遮挡”，
而不是稳定训练成功。

## 运行结果

正式实验于 2026-08-02 22:10–22:39 在物理 GPU 0 上完成，200/200 次联合
更新均正常执行：

- 无 OOM、NaN、残差越界或跳过更新；
- 实际残差最大 `0.099987`；
- 原始残差最大 `0.481959`，未触发 `2.0` 安全线；
- 接近残差上限的像素比例最高 `1.736%`；
- 裁剪前梯度范数最大 `3.25948`；
- 模型峰值显存 `11,457,088,000` bytes，约 10.67 GiB；
- 总耗时 `1734.6` 秒，约 28.9 分钟。

训练集以细结构 K=3 Point Rel 选择的最佳检查点为 step 950：

| 范围与指标 | step 800 | step 950 | 相对变化 |
|---|---:|---:|---:|
| Train K=0 Point Rel | 5.273% | 5.222% | −0.96% |
| Train K=3 Point Rel | 4.505% | 4.304% | −4.48% |
| Train K=3 细结构 Point Rel | 5.097% | 4.889% | −4.09% |
| Validation K=0 Point Rel | 8.654% | 8.583% | −0.82% |
| Validation K=3 Point Rel | 8.883% | 9.029% | +1.65% |
| Validation K=3 细结构 Point Rel | 8.651% | 8.465% | −2.15% |

step 950 同一检查点下，训练集 K=3 相比 K=0 的 Point Rel 从 `5.222%`
降低到 `4.304%`，SSR 相对改善约 `17.6%`。但是验证集全图 K=3 仍比
K=0 更差，说明限制残差只解决了联合训练的可执行性，没有解决留出域泛化。

## 结论

Exp28 支持以下结论：

1. `0.1*tanh(raw/0.1)` 能让 Exp16 在 step 820 失败的联合阶段稳定跑完；
2. 训练集二维头和 SSR 均继续改善，SSR 的训练域贡献有所增强；
3. 仅 `1.736%` 像素接近上限，稳定并非来自把全部输出压成常数；
4. 验证集全图 K=3 继续退化，因此残差约束不是泛化问题的完整解法；
5. 需要更长训练观察验证退化是早期暂态还是持续过拟合，后续由 Exp29 承接。
