# exp3_fine_structure_visualization

## 实验目标

补充 exp2 未能直接展示的 MoGe-3 核心卖点：细杆、链条、椅腿和遮挡边界等结构在二维
深度图中可能看起来正常，但离轴观察三维点图时会暴露弯曲、涂抹和前后景粘连。本实验
参照论文 Figure 1、Figure 3 和 Figure 4，生成精修迭代过程的局部三维可视化。

## 可视化设计

每个面板固定同一图像区域和同一虚拟相机，按列显示：

1. RGB 裁剪；
2. 真值；
3. K=0 基础点图；
4. K=1；
5. K=3；
6. K=5。

第一行显示视差；第二行先在完整 RGB 上用红色虚线框标出 ROI，再把对应点图绕局部
中心旋转后以 RGB 点云渲染。另生成 GT/K=0/K=3 的往返旋转 GIF，使二维图中不明显
的三维扭曲在视角变化下可见。

## 区域选择

参照论文附录 B.1 的粗检测阶段，在真值视差上组合：

- 下采样再上采样尺度 8、16、32 的多尺度残差；
- 核尺寸 3、5、9、17 的白/黑 top-hat；
- 基于 MAD 的三倍鲁棒标准差阈值。

当前没有引入 SAM2 的分割扩张，因此这些区域只用于定性诊断，不能称为论文完整的
局部评测掩码。参照论文 Figure 4 的红色虚线框展示方式，我们人工固定包含吊灯链条、
梯子细杆的训练帧 `ai_036_002/frame.0042`，再在该帧内选择 K=0 到 K=3 点图 Rel 改善
最大的候选窗口。独立验证帧固定为包含竖杆结构的 `ai_055_003/frame.0057`，其窗口只按
候选掩码支持度选择，不使用预测质量，避免为验证集挑选有利区域。

## 实验配置与复现

- 来源检查点：exp2 第 2000 步检查点；
- 输入分辨率：192×256；
- 候选窗口：96×96，步长 16；
- 最大精修次数：K=5；
- 离轴视角：yaw 28°、pitch -8°；
- 运行设备：物理 GPU 2；
- 法线预测：关闭。

完整参数保存在 [config.json](config.json)。服务器环境配置完成后，可在仓库根目录执行：

```bash
bash experiment/stage1_learning_capability/runs/exp3_fine_structure_visualization/run.sh
```

## 实验结果

### 训练帧：吊灯链条与梯子

训练帧 `ai_036_002/frame.0042` 的候选窗口为 `[48, 0, 144, 96]`。离轴点云中，
K=0 在吊灯链条及相邻表面附近存在明显飞点和厚度畸变；K=1 已有明显改善，K=3 最接近
真值。该现象与论文 Figure 4 所强调的“通过三维精修逐轮分离细结构与背景”一致。

下表是候选窗口上的诊断指标。它们使用附录 B.1 的粗候选区域，但没有 SAM2 分割扩张
和逐实例局部对齐，因此不能与论文表格中的 Local 指标直接比较。

| 迭代 | 点图 Rel | 深度 Rel | 深度 δ1.01 | 边界 F1 |
|---:|---:|---:|---:|---:|
| K=0 | 6.374% | 6.196% | 39.70% | 0.8689 |
| K=1 | 3.719% | 3.307% | 47.54% | 0.9056 |
| K=3 | 2.765% | 1.609% | 68.26% | 0.9159 |
| K=5 | 3.341% | 1.956% | 55.83% | 0.8882 |

K=0 到 K=3 的点图 Rel 相对下降 56.62%，深度 Rel 相对下降 74.03%，δ1.01
增加 28.57 个百分点，边界 F1 增加 0.0469。K=4 后开始回退，说明当前只在 24 帧上
训练的 SSR 尚未复现论文中约 K=5 后才趋于稳定的迭代行为；当前检查点的推荐推理步数
仍是 K=3。

### 独立验证帧：竖向细杆

验证帧 `ai_055_003/frame.0057` 的窗口 `[16, 96, 112, 192]` 完全根据真值细节
候选强度选择，不使用预测误差。K=3 的二维深度 Rel 比 K=0 略好，但点图 Rel 和边界
F1 变差；离轴点云也能看到竖杆及邻近表面逐步变厚和扭曲。K=5 的退化更加明显。

| 迭代 | 点图 Rel | 深度 Rel | 深度 δ1.01 | 边界 F1 |
|---:|---:|---:|---:|---:|
| K=0 | 9.390% | 7.320% | 5.96% | 0.8861 |
| K=3 | 9.874% | 6.889% | 7.20% | 0.8616 |
| K=5 | 10.955% | 7.699% | 6.21% | 0.8163 |

K=0 到 K=3 的深度 Rel 相对下降 5.88%，但点图 Rel 相对上升 5.15%，边界 F1
下降 0.0245。这恰好说明论文采用三维点图指标和离轴可视化的必要性：单看正视二维
深度图，可能把实际的三维退化误判为改善。

## 结论与下一步

本实验已经建立了适合展示 MoGe-3 核心卖点的可视化方式：以全图红色虚线框定位细结构，
在同一窗口、同一尺度和同一虚拟相机下并列展示 GT 与 K=0/1/3/5，并用旋转动画检验
结构在视角变化后是否仍然成立。训练帧的吊灯链条区域确实呈现了论文所描述的三维精修
效果。

但该效果目前只在参与训练的细结构上成立。独立餐厅场景仍然退化，因此不能据此声称
已复现论文级泛化。下一次训练实验应增加包含栏杆、灯链、椅腿和遮挡边界的合成场景，
保持本实验的独立验证面板固定；只有验证集 K=3 的点图 Rel、边界 F1 和离轴几何同时
改善，才把“细结构三维效果”视为复现成功。

## 补充：与 exp2 同源的细杆 GIF

exp3 本身没有训练新权重或建立新数据划分；本次可视化严格复用 exp2 的 step 2000
检查点、train/val 数据及预先锁定的毛巾架和木格栅区域。结果也应与 exp2 相同：
train 点图 Rel 为 7.409%→2.676%，val 为 9.389%→10.071%。动画分别见
[train GIF](artifacts/rod_visualization/train_rod_orbit.gif) 和
[val GIF](artifacts/rod_visualization/val_rod_orbit.gif)。

最左列显示完整输入及红色裁剪框，第二列显示 GT-only 局部掩码。exp3 没有独立 test
划分；这些文件是对 exp2 行为的另一套展示记录，而不是一项新的定量实验。复现入口为
[render_rod_gifs.sh](render_rod_gifs.sh)。动画为单向 −90°→+90°，每步 4°、每帧
110 ms，共 46 帧和 5.06 秒。
