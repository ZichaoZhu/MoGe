# Exp20：SSR 无运行状态的即时批统计推理

## 实验问题

Exp19 在完全不改权重时，用 100 张训练图重校准 BatchNorm running statistics，
使 eval 最大残差从 1.0458 降到 0.8124、离群图从 6 张降到 2 张，并小幅改善
K=3/K=5 指标。但同一套运行统计仍需混合 K=1/2/3 三轮不同分布，未能根治。

本实验回到未经重校准的 Exp15 step 800 原始检查点。Base 保持正常 eval；SSR
也保持 eval，但临时令每个 `BatchNorm1d` 不读取 running mean/variance，而是
对当前单张图、当前递归轮次的稀疏特征即时求统计。上下文结束后原运行缓冲会恢复，
期间既不更新权重，也不更新或保存任何 BN 缓冲。

该策略等价于让每一轮自行适应当前特征分布，同时保留训练得到的 BN 仿射参数。
它不是论文公开设定，而是针对当前复现中未公开归一化细节的诊断性部署策略。

## 固定设计

- 检查点、100/16/16 数据、ROI、384×512、`num_tokens=2500` 均与
  Exp15–19 相同；
- 单图推理 batch 1，K=0/1/3/5 完整评测；
- 对全部 132 张图扫描 K=1/2/3 逐轮残差；
- 与原始 stored-running-statistics 结果比较；
- 残差安全阈值仍为 0.5，不放宽；
- 不训练、不保存新检查点、不改变原文件。

## 运行结果

冒烟测试于 08:41:58–08:42:25 完成，三个划分各一张图的最大残差为 0.2662，
没有越界。正式实验于 2026-08-02 08:42:31–08:45:05 在物理 GPU 1 上完成，
用时 2 分 34 秒；监督程序在 08:42:31 和 08:52:31 检查，实际间隔
600.067 秒并确认正常结束。检查点 SHA-256 在基线、残差扫描和指标评测中
完全一致。

### 残差离群被完全消除

| 归一化策略 | eval 最大 \(|\Delta\log Z|\) | 越界图数 |
|---|---:|---:|
| 原始 running statistics | 1.0458 | 6/132 |
| Exp19 batch 8 重校准 | 0.8124 | 2/132 |
| 本实验单图即时统计 | **0.4644** | **0/132** |

即时统计下 K=1/2/3 在 train 的最大残差为
`0.3681 / 0.3284 / 0.4644`，val 为
`0.3435 / 0.2658 / 0.2869`，test 为
`0.2745 / 0.2521 / 0.4264`，九个组合均低于 0.5。这与 Exp18 的
Base eval / SSR train 结果在浮点误差内一致，证明无需让整个模型进入 train；
只要绕开 SSR 的运行统计即可复现安全残差。

### 训练拟合显著改善，但留出集退化

下表为 K=3 Point Rel；括号是相对原始 running-statistics 推理的变化，正数
表示误差下降。

| 范围 | 原始 | 单图即时统计 |
|---|---:|---:|
| Train 全图 | 4.5208% | **3.9189%（+13.31%）** |
| Train 结构 | 5.1243% | **4.6926%（+8.42%）** |
| Val 全图 | **8.9050%** | 9.0677%（−1.83%） |
| Val 结构 | **8.7467%** | 8.9054%（−1.81%） |
| Test 全图 | **6.8930%** | 7.3402%（−6.49%） |
| Test 结构 | **9.3324%** | 9.9832%（−6.97%） |

K=5 的方向更明显：训练全图/结构相对原始改善 `7.74% / 3.29%`，验证退化
`1.69% / 1.90%`，测试退化 `10.71% / 12.22%`。因此即时统计虽然从数值上
彻底解决爆点，却不是可直接采用的泛化方案。

逐帧结果并非由少数极端图片造成：K=3 全图相对原策略改善
`97/100` 张训练图，却只改善 `6/16` 张验证图和 `5/16` 张测试图；结构 ROI
改善 `41/53` 个训练区域，但验证、测试各自唯一的锁定 ROI 都未改善。两个验证
场景的平均 Point Rel 均上升；两个测试场景也均上升，其中
`ai_050_001` 平均增加 0.692 个百分点。这是系统性的训练/留出分布差异。

## 原因分析

Exp17–20 已把当前结果不佳拆成三个相互关联、但不同的问题：

1. **训练与推理统计失配。** 训练每步 global batch 8 实际由八次
   microbatch 1 前向组成；BN 每次看到单图即时统计。正常 eval 却使用累计
   running statistics，因此会产生训练中从未出现的 1.0458 递归残差。
2. **权重依赖单图统计。** 改回训练时的单图统计后，训练 K=3 Rel 立刻再下降
   8%–13%，说明 SSR 权重确实学会了这一归一化条件，不是完全没有学习。
3. **小数据单域过拟合。** 同一策略在 val/test 反而退化，尤其测试结构退化
   6.97%。权重与单图统计的组合拟合了 100 张 Hypersim 训练分布，却没有形成
   跨留出场景的稳定修正。

原始 running statistics 在留出集上有时像一种分布平滑，指标比单图统计好，
但会在少数训练图上产生严重爆点；Exp19 的 batch 8 人口统计是当前更好的折中：
K=3 六个范围都小幅改善且离群减少到两张，但仍不满足安全阈值。没有一种现有策略
同时达到“零离群、训练拟合好、留出集不退化”。

这也解释了为什么之前只看平均 Rel 会低估问题：平均指标混合了大部分正常区域和
少数爆点；而只看训练 GIF 又会高估方法，因为与训练时一致的即时统计可显著提高
训练拟合，却不能代表泛化。

论文使用 25 个异构数据集、16 张 A100 和全局 batch 96；当前只有 100 张
Hypersim，且真实前向 batch 为 1。更重要的是，论文没有公开稀疏残差块的
归一化类型，`BatchNorm1d` 是当前复现时补全的结构细节。因此结论应表述为：
**MoGe-3 的稀疏三维精修思想具有学习能力，但当前复现的 BatchNorm 与小批量训练
组合不适合共享递归 SSR**，而不是论文方法本身无效。

## 结论与下一步

1. Exp20 完整证明 stored running statistics 是六张爆点的必要条件；
2. 直接采用单图即时统计可保证当前 132 张残差安全，但会扩大训练/留出差距，
   不作为最终部署策略；
3. 下一步在不改卷积权重的前提下，为 K=1、K=2、K=3 分别校准独立的
   batch-8 人口统计，并在相应递归轮次加载对应统计；它能检验问题是否来自
   “一套 BN 缓冲混合三种递归分布”；
4. 若轮次独立统计仍不能兼顾稳定与泛化，就停止围绕 BN 缓冲微调，改用
   GroupNorm/LayerNorm 等无 batch 状态归一化，并从零 SSR 重新进行小规模训练。
