# Exp16：正确 Detached 预热后的短程联合阶段

## 实验问题

Exp15 从原始 MoGe-2 与零 SSR 出发，让二维头和 detached SSR 渐进共适应，
取得当前最佳百图训练结果。Exp16 从该 step 800 最佳点出发，解除 SSR 输入
detach，使 K=1/2/3 refined loss 能够同时更新二维头和 SSR；DINO 继续冻结。

这与 Exp14 的区别是：Exp14 的 SSR 先在完全固定 Base 上学成，随后突然移动
二维头，产生表示错配；Exp16 的二维头和 SSR 已在 Exp15 的 800 步 detached
阶段持续共同适应，更接近论文从预热到联合阶段的真实切换。

## 配置

- warm start：Exp15 step 800，SHA-256
  `f602855f9e5628e27393734f121a5ffa2f485e1cbfd1c410a2ed0850ca5200fa`；
- 数据与 ROI 保持 100/16/16 不变；
- 新增 200 步，step 801–1000 全部为 joint；
- SSR/head 学习率降为 `2e-6 / 5e-7`；
- DINO 冻结，全局 batch 8，训练 K=3；
- 每 50 步完整评测，以训练结构 K=3 Point Rel 选择检查点；
- 最大绝对对数残差限制 0.5；
- 每 600 秒记录训练和 GPU 状态。

## 解释

Exp15 在训练期间观测到的残差峰值已经达到 `0.461`，接近 0.5 阈值。Exp16
即使把 SSR/head 学习率分别降到 `2e-6 / 5e-7`，联合阶段仍在 20 步内遇到
`0.5331`。这说明当前检查点至少存在以下两种可能：

1. 联合梯度快速放大了 SSR 已经偏大的修正；
2. Exp15 只记录随机训练批次峰值，未覆盖全部 100 张图片，step 820 恰好抽到
   一个起点本身就超过阈值的困难样本。

仅凭本次失败不能区分二者。step 820 的 8 张图由 seed 161 确定，后续先对
Exp15 原始检查点执行完整 train/val/test 的逐帧、逐迭代残差扫描，再决定是
降低联合学习率、增加残差约束，还是先处理少数离群样本。直接放宽 0.5 阈值会
掩盖递归过修正，因此不采用。

## 结论

Exp16 没有证明短程联合训练有效，但提供了明确的负结果：正确 detached 预热
解决了组件共适应问题，却没有自动保证联合阶段的递归稳定性。下一步必须先判定
残差越界是起点离群还是联合更新造成，不能盲目继续延长训练。
