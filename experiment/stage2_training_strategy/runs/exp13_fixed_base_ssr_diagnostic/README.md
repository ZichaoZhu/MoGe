# Exp13：固定 Base 的 SSR 多图诊断实验

## 实验问题

Exp11/12 中训练集的主要改善来自 Base/2D Head，SSR 在 K=0→K=3
之间只产生约 0.4% 的相对改善，同时验证集和测试集恶化。本实验固定原始
MoGe-2 Base 和全部二维头，只允许 SSR 更新，用来区分：

1. SSR 本身能否在 100 张 Hypersim 图像上学习稳定的多图局部修正；
2. 前序失败主要来自 Base 联合训练过拟合，还是来自 SSR 架构、损失或分辨率；
3. K=1/3/5 是否呈现论文所报告的稳定迭代趋势。

这是诊断性消融，不是论文默认的完整联合训练配置。

## 受控设置

- 数据固定为 Exp11 的 100/16/16 train/val/test；
- 从同一个原始 MoGe-2 Base 和零初始化 SSR 开始；
- Base、neck 和全部二维输出头参数完全冻结；
- 训练 K=3，仅使用 K=1/2/3 几何损失更新 SSR；
- 对 `2e-6`、`1e-5`、`2e-5` 三个 SSR 学习率做同随机种子的受控扫描；
- 384×512，global batch 8，每个分支最多 800 步；
- 每 100 步评测一次；
- 检查点由 53 个训练集锁定细结构区域（52 个确认候选加 Exp12
  预锁定训练样本）的 K=3 Point Rel 选择；
- 完成后在完整 train/val/test 上统一评测 K=0/1/3/5。

细结构区域仅由训练前已经确认的 RGB 与 GT 产生，不读取模型预测。所有服务器
写入必须位于 `/mnt/data/home/zhuzichao` 下。

## 判别规则

- 如果至少一个学习率使训练细结构 K=3 明显优于 K=0，且 K=5 不回退，
  说明 SSR 主路径可以工作，前序问题更可能来自 Base 过拟合或联合训练日程。
- 如果训练细结构也不改善，或 K=5 持续回退，则优先检查 SSR 架构假设、
  局部损失、体素分辨率与输入分辨率。
- 如果只改善训练集而验证/测试恶化，说明 SSR 也会在当前百图设置下过拟合，
  后续应增加结构多样性或正则化，而不是继续延长训练。

## 运行结果

实验于 2026-08-02 02:28 启动正式训练，三个单卡分支分别使用物理
GPU 1、0、2，并于 04:05–04:10 完成。每个分支训练 800 步，随后在完整
100/16/16 张 train/val/test 上统一评测 K=0/1/3/5。训练及后评测均未出现
OOM、NaN、梯度更新跳过或残差安全阈值越界。

三个分支在所有时间点的 K=0 指标逐项一致，证明 Base、neck 和二维头参数确实
保持冻结，以下差异只来自 SSR。

0.7894，说明仅降低 Point Rel 不能保证边界锐度同步改善。

## 结论

本实验将前序问题拆成了两个部分：

1. **SSR 主路径有效。** 固定 Base 后，SSR 可以在百图训练集上把结构 Point
   Rel 降低 22.68%，因此前序结果差不能归因于“SSR 完全没有学习能力”。
2. **小数据下存在明确的学习率与泛化权衡。** 高学习率取得强训练拟合，但对未见
   测试场景和额外迭代不稳定；低学习率可以保持 K=5 稳定，却只有小幅收益。
3. **Exp11/12 的主要矛盾得到验证。** 当时 Base 已经先发生过拟合，而 SSR
   又使用比论文低 400–500 倍的学习率，最终表现为 Base 变化主导、SSR
   精修很弱。本实验移除 Base 变化后，SSR 的作用变得清晰。
4. **结果不能与论文完整训练等价。** 论文使用多数据集、大 batch、真实数据维持
   Base 泛化，并报告较稳定的 K 迭代；当前仅有 100 张 Hypersim、384×512，
   中高学习率的测试退化正是这种规模差异的表现。

因此没有单一无条件最优分支：

- 若目标是验证训练集极限拟合，选择 `lr_2e5` 的 step 700；
- 若目标是验证额外迭代与未见结构稳定性，选择 `lr_2e6` 的 step 800。

下一项实验采用训练拟合分支进入短程 Head+SSR 联合阶段，并保持 DINO 冻结，
用来单独判断二维几何头解除冻结后能否改善全图误差，同时保住已学到的结构修正。
只有该阶段稳定后，才有理由进一步开放 DINO。
