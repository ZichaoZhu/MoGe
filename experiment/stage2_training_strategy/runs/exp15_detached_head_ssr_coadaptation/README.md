# Exp15：Detached 阶段二维头与 SSR 渐进共适应

## 实验问题

Exp13 证明固定 Base 时 SSR 可以学习；Exp14 证明先把 SSR 在固定 Base 上训强，
再突然解冻二维头，会让 K=0 改善但破坏已经学到的 SSR，最终 K=3 没有超过
联合前起点。

Exp15 从同一个 MoGe-2 和零初始化 SSR 重新开始。二维头从第一步起接受 K=0
监督，SSR 同时接受 K=1/2/3 监督，但精修输入在 Base 侧 detach。这样二维头
与 SSR 会在训练过程中逐渐适应彼此变化的输入分布，同时 refined loss 不会
反向破坏 Base。这比 Exp14 更接近论文前 5000 步预热阶段的梯度路由。

本实验仍是百图小数据机制验证，不宣称完整论文复现。DINO 保持冻结，以隔离
二维头与 SSR 的共适应作用；如果本阶段稳定，下一步才进入短程联合反向。

## 配置

- 数据：与 Exp13/14 相同的 100/16/16 张 Hypersim；
- 初始化：原始 MoGe-2，SSR 输出层严格零初始化；
- 分辨率：384×512，训练 K=3；
- DINO 冻结，neck/points head 与 SSR 可训练；
- 全部 800 步保持 `detach_base_from_refiner=True`；
- SSR/head 学习率：`2e-5 / 1e-6`；
- global batch 8，microbatch 1，无数据增强；
- 每 100 步评测完整 train/val 和锁定结构 ROI；
- 以训练结构 K=3 Point Rel 选择检查点；
- 每 600 秒记录 GPU、进程和最新训练/评测状态。

## 运行结果

冒烟和正式训练均使用物理 GPU 1。正式训练从 2026-08-02 05:37:38 运行至
07:21:50，共 104.1 分钟；模型自身峰值显存为 10.89 GiB。13 次固定间隔
监督检查覆盖启动、训练和结束，全程没有 OOM、NaN、梯度更新跳过或残差越界。
最大裁剪前梯度为 `2.591`；最大绝对对数深度残差为 `0.461`，最后一步为

## 贡献拆分

二维头 K=0 相对原始 K=0 的全图 Point Rel 在 train/val/test 分别改善
`11.87% / 2.78% / 6.29%`；结构区域分别改善
`9.15% / 14.67% / 2.77%`。因此二维头的更新既能拟合训练集，也保留了一部分
留出场景收益。

同一个最终检查点内，SSR 的 K=0→K=3 贡献为：

- 训练全图和结构改善 `14.26% / 17.80%`；
- 验证全图和结构退化 `2.90% / 7.88%`；
- 测试全图和结构退化 `0.50% / 2.92%`。

逐帧上，K=3 相对 K=0 改善 train/val/test 的
`91/100、6/16、8/16` 张；结构 ROI 为 `43/53、0/1、0/1`。这比 Exp14
训练全图的 `89/100` 更稳定，训练结构的改善数相同；留出集仍没有形成稳定
正收益。

相对原始 K=0，最终流水线 K=3 的 train 全图/结构分别总改善
`24.44% / 25.32%`。它也优于 Exp13 固定 Base 最佳检查点的
`4.725% / 5.306%`，达到 `4.521% / 5.124%`。这证明二维头与 SSR 在
detached 阶段渐进共适应，能够把两个组件的训练收益正确叠加，解决 Exp14
“先固定 Base 训强 SSR、再突然移动 Base”造成的表示错配。

## 剩余问题

K=5 没有复现论文中的稳定饱和行为。相对 K=3，train/val/test 全图分别退化
`6.30% / 5.31% / 2.80%`，结构分别退化
`7.88% / 4.07% / 6.29%`。最终残差峰值已达到 `0.461`，接近 0.5 安全上限，
说明反复应用共享 SSR 时存在过修正。

训练 Boundary F1 在 step 800 的 K=0/K=3 为 `0.8006 / 0.7949`。因此 Point
Rel 和结构 Rel 的明显下降并不等价于边缘一定更锐利；当前损失仍可能用轻微边缘
平滑换取整体点位置误差。

验证和测试各只有两个独立场景，锁定结构 ROI 更各只有一个，不能把单个结构数值
当成稳定统计；但全图逐帧改善比例和 K=5 一致回退仍足以证明当前百图训练存在
泛化与递归稳定性问题。论文使用 17 个合成数据集、8 个真实/重建数据集和全局
batch 96，本实验不具备相同的数据多样性。

## 结论与下一步

Exp15 已完成当前最重要的机制验证：

1. 从零 SSR 开始，让二维头接受 K=0 监督、SSR 在 detach 输入上接受
   K=1/2/3 监督，训练过程稳定；
2. 二维头和 SSR 的训练收益能够叠加，百图训练结构 Point Rel 总改善 25.32%；
3. 当前实现并非只能做单图过拟合，百图训练集上也具有明确学习能力；
4. 仍不能宣称泛化或完整论文复现，尤其 K=5 和留出细结构失败。

下一项实验从 Exp15 最佳点进入短程联合阶段，但继续冻结 DINO，只开放 refined
loss 到二维头的梯度，并显著降低 SSR/head 学习率。这样可以直接验证正确
detached 预热后，论文第二阶段联合反向是否还能继续提高训练拟合，而不会再次引入
Exp14 的突然表示错配。
