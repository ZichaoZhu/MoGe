# Exp14：二维几何头与 SSR 短程联合训练

## 实验问题

Exp13 已证明固定 Base 时 SSR 本身能够在百图训练集上学习结构修正，但中高
学习率存在测试泛化和 K=5 稳定性问题。Exp14 从 Exp13 训练拟合最佳分支
`lr_2e5` 的 step 700 检查点出发，只解除 neck/二维点图头冻结，让它们与
SSR 联合训练；DINO 主干继续冻结。

本实验只回答一个问题：二维几何头参与联合反向后，能否降低 K=0 全图误差，
同时保住 SSR 已学到的 K=3 结构收益。它是从论文阶段一到阶段二之间的受控诊断，
不是完整论文联合阶段；只有该阶段稳定后才考虑开放 DINO。

## 固定配置

- 数据保持 Exp13 的 100/16/16 train/val/test；
- warm start：Exp13 `lr_2e5`、step 700、SHA-256
  `bcf6a3652cc9656a41bf3953ad7b621a5177937f0a35f068a71ee0bde91f034c`；
- DINO 冻结，neck、points head 和 SSR 可训练；
- 训练 K=3，新增 200 步；
- SSR/head 学习率分别为 `2e-6`、`1e-6`；
- global batch 8，microbatch 1；
- 每 50 步评测完整训练/验证集和锁定结构区域；
- 检查点仍按训练结构 K=3 Point Rel 选择；
- 每 10 分钟记录 GPU、进程、最新训练和评测状态。

## 运行结果

冒烟测试与正式训练均使用物理 GPU 1。正式训练从 2026-08-02 04:45:23
运行至 05:17:00，共 31.4 分钟；模型自身峰值显存为 10.73 GiB。全程没有
OOM、NaN、梯度更新跳过或 SSR 残差越界。最终模型最大绝对对数深度残差保持
全程最高为 0.369，最后一个批次为 0.173，没有发生 Exp10/11 式数值坍塌。

下表全部来自同一个离线评测器。`起点 K=0/3` 是 Exp13 step 700；
`最终 K=0/3/5` 是 Exp14 step 900，数值为 Point Rel，越低越好。

| 范围 | 划分 | 起点 K=0 | 起点 K=3 | 最终 K=0 | 最终 K=3 | 最终 K=5 |
|---|---|---:|---:|---:|---:|---:|
| 全图 | Train | 5.983% | **4.725%** | 5.650% | 4.745% | 5.091% |
| 全图 | Val | **8.901%** | 9.044% | 8.759% | 9.094% | 10.244% |
| 全图 | Test | 7.319% | 7.598% | **7.136%** | 7.311% | 7.586% |
| 结构 | Train | 6.862% | **5.306%** | 6.500% | 5.374% | 5.813% |
| 结构 | Val | 9.503% | **8.348%** | 8.363% | 9.016% | 8.824% |
| 结构 | Test | 9.326% | 9.783% | **9.043%** | 9.771% | 10.557% |

二维头更新本身有效。最终 K=0 相对起点 K=0 的全图 Point Rel 在
train/val/test 分别改善 `5.56% / 1.60% / 2.50%`；锁定结构区域分别改善
`5.27% / 11.99% / 3.03%`。训练 K=0 Boundary F1 也从 `0.8000` 提升到
`0.8119`。

但是 SSR 没有随二维头一起泛化。在最终 step 900 内部比较 K=0→K=3：

- 训练全图和结构 Point Rel 改善 `16.02% / 17.33%`；
- 验证全图和结构退化 `3.82% / 7.81%`；
- 测试全图和结构退化 `2.45% / 8.05%`。

逐帧上，K=3 相对 K=0 只改善 train/val/test 的
`89/100、6/16、3/16` 张；结构 ROI 为 `43/53、0/1、0/1`。最严重的训练
退化集中在 `ai_001_001`：例如 frame 0014 的 K=0/K=3/K=5 全图 Point Rel
为 `0.929% / 2.081% / 3.133%`。这说明当前 SSR 会破坏本来已经很准确的
Base，尚未学会在无需修正的样本上输出接近零的残差。

K=5 也没有复现论文的稳定饱和行为。相对 K=3，最终 K=5 的 train/val/test
全图 Point Rel 再退化 `7.28% / 12.65% / 3.76%`。因此当前模型只应使用
K=3，且不能把训练均值改善解释成稳定泛化。

## 结论

本实验否定了“在固定 Base 上先把 SSR 训强，再突然解冻二维头”这一顺序：

1. 二维头可以稳定改善 K=0，说明此前结果差不是 Base 完全无法学习；
2. SSR 也保留了训练集上的正向修正，说明 SSR 主路径没有失效；
3. 但二维头改变 Base 点图和体素壳分布后，已经基于旧 Base 学到的 SSR 需要
   重新适配。200 步后训练 K=3 仅追回到接近起点，验证结构反而明显恶化；
4. 当前主要矛盾是组件协同、样本多样性和递归稳定性，而不是 OOM 或数值爆炸。

论文在 detached 阶段并不固定整个 Base：K=0 几何分支继续更新，SSR 只切断
到 Base 的反向梯度，因此 SSR 从零初始化开始跟随缓慢变化的 Base 输入分布学习。
下一项受控实验应从同一个 MoGe-2 初始化重新开始，让二维头与 SSR 在 detached
阶段同步、渐进地适配；DINO 暂时保持冻结，避免再次混入第三个变量。
